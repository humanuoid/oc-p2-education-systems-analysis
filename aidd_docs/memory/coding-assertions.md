# Coding Assertions

## Before commit

| Order | Command | Checks |
| ----- | ------- | ------ |
| 1 | re-exécuter le notebook modifié dans Jupyter | cellules rejouées, sorties à jour |
| 2 | relire le diff | rien d'inutile, rien hors sujet |

## Before push

- Accord explicite de l'utilisateur requis avant tout commit et tout push
- Pas de lint ni de tests automatisés câblés sur ce projet

## Behavior

Rien n'est commit/push sans l'accord explicite de l'utilisateur.
